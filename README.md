## Documentation

### What it does

Ephemeral file sharing - drag, drop, share a link that expires. It does one thing, well.

### Who it is for

- Vibe coders who prompt and ship
- Web developers who care about taste
- Anyone tired of heavy tools

### How it works

1. Clone the repo
2. Run the dev server for your language (WebRTC + Vite)
3. Open, use, and export

```bash
git clone https://github.com/knownasrazi/filedrop-ephemeral.git
cd filedrop-ephemeral
# follow language quick start inside
```
