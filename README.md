## Preview

> Files that vanish on purpose. - built for vibe coders and web developers who ship.

## Stack

- Vite + React + TypeScript
- Tailwind CSS (cream palette)
- Biome for lint and format

## Get started

```bash
git clone https://github.com/knownasrazi/filedrop-ephemeral.git
cd filedrop-ephemeral
bun install
bun run dev
```
filedrop-ephemeral/
  src/
    App.tsx      # app shell
    index.css    # cream tokens
  index.html
  vite.config.ts
  package.json
```

## Cream tokens

Cream, stone, and ink - low contrast, high taste.
